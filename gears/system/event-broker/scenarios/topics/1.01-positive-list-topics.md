# List topics visible to the caller

Read-only introspection. Returns the topics the caller's principal is authorized to see in the current tenant.

## Request

```http
GET /v1/topics HTTP/1.1
Host: broker.example.com
Authorization: Bearer <tenant-token>
```

## Expected response

- `200 OK`
- Body is a page of topic DTOs, each projected from that topic's registered instance: `id`, `description`, and `retention` are the instance's own values, with `retention` reported in canonical units. Only topics the principal may `consume` or otherwise see are included. The page shape is the platform's, so a caller pages with `limit`/`cursor` rather than reading a bare array.

```json
{
  "items": [
    {
      "id": "gts.cf.core.events.topic.v1~acme.orders.v1",
      "description": "Order lifecycle events",
      "retention": "PT168H"
    },
    {
      "id": "gts.cf.core.events.topic.v1~acme.shipments.v1",
      "description": "Shipment dispatch events",
      "retention": null
    }
  ],
  "page_info": {
    "next_cursor": null,
    "prev_cursor": null,
    "limit": 25
  }
}
```
